# memory
Project: CRM REST API (Express 5 + Mongoose 9, TS, CommonJS). Client: ../app.
Entry: server.ts -> connectDB() -> app.listen(env.port). app.ts = etag "weak" + cors() + express.json() + apiCacheHeaders on /api + route mounts.
Caching: middleware/cache.middleware.ts sets GET `private, max-age=0, must-revalidate` + `Vary: Authorization`, non-GET `no-store`. Clients revalidate with If-None-Match against Express ETags.
Scripts: dev=nodemon server.ts (ts-node). No build/start/test script.
Env: PORT, MONGO_URI, JWT_SECRET, GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, opt GOOGLE_REDIRECT_URI, opt CLIENT_URL(def http://localhost:3000), MAIL_USER, MAIL_PASSWORD. config/env.js exposes port, mongo_url, jwt_secret, client_url, google_client_id/secret/redirect_uri. Legacy unused CLIENT_ID/CLIENT_SECRET in .env = a different GCP client than GOOGLE_CLIENT_ID.
Mounts: /api/auth, /api/workspaces, /api/workspace-members, /api/modules, /api/collections, /api/columns, /api/records, /api/record-values, /api/api-key.
Auth: middleware/auth.middleware.ts `protect` — Bearer JWT (payload {userId}) first, else x-api-key -> User.apiKey+isActive. Sets req.user.id (AuthRequest).
Tokens: services/jwt.service.ts createToken(userId) 7d. services/apiKey.service.ts generateApiKey() -> `crm_<32B hex>`.
Public routes: POST /api/auth/register, /api/auth/login, GET /api/auth/google, GET /api/auth/google/callback. GET /api/auth/me is protected. All others protected.
Google OAuth: server-side code flow, no SDK dep (global fetch). services/google.service.ts builds consent URL, exchanges code, fetches /oauth2/v3/userinfo. CSRF state = short-lived JWT signed with JWT_SECRET carrying {nonce,mode}. Callback upserts by googleId|email then redirects to `${client_url}/auth/callback#token=` (fragment, never query). Errors redirect with #error=<code>: not_configured|invalid_state|missing_code|no_email|exchange_failed|access_denied.
Route shape: nested resources keyed by parent id on POST/GET (/:moduleId, /:collectionId, /:workspaceId); PUT/DELETE keyed by own id. record-values POST is "/" .
Models: User(googleId, authProvider local|google; password+lastName required only when authProvider=local), Workspace, WorkspaceMember(role owner|admin|member|guest, status active|pending|inactive), Module(visibility private|workspace|public), Collection, Column, Record, RecordValue(value:any), Activity, ApiToken(tokenHash), Comment, File, Notification. All timestamped.
Hierarchy: Workspace > Module > Collection > Record > RecordValue; Column belongs to Module.
Convention: after any mutation call touchWorkspace(workspaceId) from utils/workspaceHelper.ts.
Naming: controllers/wrokspace.controller.ts is a typo, kept as-is.
Unwired: services/otp.service.ts (nodemailer) has no route/controller; ApiToken model unused by /api/api-key (uses User.apiKey).
tsconfig include omits scripts/** (target es2022, commonjs, strict, outDir ./dist).
Gaps: no global error handler, no input validation lib, no rate limiting, cors() fully open. Not done from REDUX-PLAN.md: flatten the {workspaces:[{workspace}]} envelope (breaking, membership fields would be lost), GET /api/workspaces/:id/bootstrap batch endpoint, record pagination. totalModules already uses one Module.aggregate (no N+1).
Uploads: /api/uploads (routes/upload.routes.ts, all protected) — GET /limits, POST+DELETE /avatar, POST+DELETE /workspace/:workspaceId. multer memoryStorage buffers -> services/cloudinary.service.ts streams to Cloudinary; nothing hits disk. Limits + allowed mime types are the single source of truth in middleware/upload.middleware.ts UPLOAD_LIMITS (avatar 5MB images-only, attachment 10MB x10) and are mirrored client-side in app/lib/imageCompression.ts UPLOAD_RULES — change both together. Server transforms enforce the real ceiling (avatar 512x512 fill/face, attachment 1920 limit, quality auto:good, fetch_format auto). Avatar public_id IS the user id so re-upload overwrites in place; User.avatarPublicId tracks it for delete. googleCallback mirrors profile.picture into Cloudinary best-effort and only when user.avatar is blank (never overwrites an uploaded picture). Env: CLOUDINARY_CLOUD_NAME/API_KEY/API_SECRET/FOLDER — added to .env as EMPTY placeholders 2026-08-22, uploads 503 until filled.
